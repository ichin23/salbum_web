## Milestone v1.3 Requirements

### Review Details
- [ ] **REV-01**: User can navigate to a dedicated review details page from a review card (feed or profile).
- [ ] **REV-02**: Review details page displays the full review content, including rating, feelings/tags, author details, and associated album information.

### Likes
- [ ] **LIKE-01**: User can view the number of likes on a review in the feed and details page.
- [ ] **LIKE-02**: User can toggle like (like/unlike) on a review from the feed and details page.
- [ ] **LIKE-03**: The UI visually indicates if the logged-in user has already liked the review.

### Comments
- [ ] **COM-01**: User can view a list of comments on the review details page.
- [ ] **COM-02**: User can add a new comment to a review from the review details page.
- [ ] **COM-03**: The number of comments is displayed on the review card (feed) and review details page.
